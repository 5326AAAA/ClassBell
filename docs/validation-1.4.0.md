## 核心场景

1. 多账号拍照同时进入提交：使用屏障验证两个账号并发执行，账号与各自照片内容一一对应。
2. 第一个账号丢失签到回复，第二个账号仍成功；查询明确未签到后，只恢复第一个账号的选图和手动提交。
3. 成功账号不会因后到的“未签到”查询而解锁，不重复提交。
4. 请求发送中、未知状态和其他账号的提交锁不会被清除。
5. 提交前查询结果会保留尚未上传的选图；处理完成后清除对应临时照片。
6. 官方预签到要求额外验证时，不取上传凭证、不上传照片、不调用提交端点。
7. 更新解析按数字比较版本，拒绝草稿、预发布及其他仓库、非 HTTPS、带凭据或额外查询参数的下载地址。
8. 日历过滤已交、过期、缺失截止时间和手动完成的作业；验证 UTC 时间、稳定且账号隔离的事件 UID、可选提醒和 UTF-8 折行。
9. 验证系统文件选择器实际输出 .ics，以及选择保存位置期间切换账号会取消写入并删除临时文件。

## 操作入口

- 多账号拍照：签到中心 → 选择关联账号 → 核对要求 → 分别选图 → 核对照片并提交；单账号拍照页也可进入多账号分别选图。
- 日历：作业 → 作业截止日历 → 保存 .ics → 用支持此格式的日历应用导入。
- 更新：使用帮助 → 检查更新。
