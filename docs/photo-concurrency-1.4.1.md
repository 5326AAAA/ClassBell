# v1.4.1 四账号拍照

本版将拍照签到并行上限从三个调整为四个。选择五个及更多账号时，后续账号在本机队列中等待空位，不会增加同时发送的照片请求数量。

操作入口为「签到中心 → 选择关联账号」，或拍照详情中的「多账号分别选图签到」。核对要求后，逐账号选择本次照片并确认对应关系，再提交。每个账号使用独立照片、会话和结果；失败账号不会中断其他账号，成功账号不重复提交。

服务器结果未知时先查询。只有匹配账号与活动的记录明确显示未签到，才恢复该账号的重选照片和手动提交入口。正在发送与已经确认成功的记录不会被这个查询清除。

1.4.0 的日历和检查更新功能保留。AI 作业讲解本轮处于方案讨论阶段，未加入 APK；后续需先解决原生题目读取与所选模型服务的连接，再设计手动选题、讲解和参考答案的核对流程。

构建、四账号并发与五账号排队验证见 [测试记录](validation-1.4.1.md)。ADB 与真实课程活动验收按用户安排留到后续。
