# ClassBell v1.5.2 · 作业一键复制与多账号功能更新

**整份作业一键复制、题图批量保存、多账号管理、应用内扫码与拍照签到、课程提醒和资料下载。**

## 功能重点

- **作业整理**：顶部一键复制整份题干和选项，每题下方可单独复制；整份或单题题图手动保存到相册 / ClassBell，文档附件不处理。
- **多账号与拍照**：账号会话、照片及结果分别管理；逐账号选图、预览和核对，最多四个拍照账号并行处理。
- **应用内扫码**：识别当前有效二维码后立即提交；明确过期时重新扫描，结果按账号显示。
- **签到中心**：查看活动名称、时间、当前状态和个人结果；停止检测的活动归档。
- **课程与提醒**：课程资料批量保存到选定文件夹，作业截止日历导出，按课程开启提醒，按用途查看所需权限。

> [!CAUTION]
> **登录与隐私说明：我没钱买服务器，项目也没有自建服务器。登录请求直接发往学习通官方，账号密码不会上传给我，请放心登录。**
>
> 勾选“记住密码”时，登录信息仅在你自己的设备上加密保存。

## 这版修复了什么

- 修复未交作业只读取一道题，按答题卡逐页读取并核对题目。
- 补齐多选题选项和空白选项标签；真实第6章作业的 25 题、49 个选项标签核对通过。
- 作业 UI 以 1.5.0 为基础，完成状态放在标题同一行右侧，删除顶部及每项作业的学习通打开入口；深绿按钮增加按压反馈。

## 下载与覆盖安装

下载本页 Assets 中的 **ClassBell-v1.5.2-debug.apk**（约 30 MB）。在手机的**夸克、其他浏览器下载列表或文件管理器**里点开 `.apk`，选择安装。已有本仓库同签名旧版时直接选择**更新 / 覆盖安装**，保留账号与设置，无需先卸载。

**ClassBell-v1.5.2-source.zip** 是完整源码，供查看和开发使用。v1.0.0 轻量版继续保留；该版本体积约 3.2 MB，签到需要跳转学习通。

位置签到当前不可用；部分官方答题、验证和预览流程按页面提示处理。
