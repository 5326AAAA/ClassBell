## 真机覆盖

| 场景 | 结果 |
| --- | --- |
| 单账号页面明确过期后再次扫描并提交新码 | 通过，2 次扫码回调、2 次提交，503 ms |
| 3 个账号中 1 个准备失败，其余 2 个并发 | 通过，失败账号未发最终请求，健康账号结果处理 65 ms |
| 预签到中断后允许新码继续 | 通过 |
| 旧码明确过期，新码成功后防重复 | 通过 |
| 已识别材料直接走生产提交链路 | 本机响应处理 17 ms |
| 未知最终回复 | 保留 UNKNOWN，不盲目重复发送 |
| 10 个合成账号走生产提交链路和本机 TLS | 最慢到达 73 ms，全部结果处理 143 ms |
| 超过本地时限的材料 | 不发送、不占锁，新码可继续 |
| 内置 ML Kit 识别合成二维码位图 | 34 ms |

以上测量从账号准备完成及识别获得材料后计时，使用本机响应，不包含人手重新对准、学校网络或学校服务器耗时。本轮没有实际课堂服务的签到提交验收。
