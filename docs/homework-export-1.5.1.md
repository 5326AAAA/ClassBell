# 作业文字与题图整理（v1.5.1）

## 使用

在作业列表更新当前账号的作业，点击对应卡片中的「题目文字与图片」。页面会读取题干和选项，按题号展示。

- 「复制全部题目文字」：一次复制整份已识别题目的题干、选项、填空数量和题型，包含简答题正文。图片位置使用编号标记，不将图片签名地址写进剪贴板。
- 「保存全部题图到相册」：手动下载本份作业的题干、选项配图与图片形式公式，保存到系统相册的 `Pictures/ClassBell`。
- 每道题下面可以分别「复制本题文字」「保存本题图片」。单题复制与单题存图使用本题内部的图片顺序。

打开页面不会下载或保存题图；只有点击保存按钮后才请求图片内容。文档附件、附件 iframe、页面头像和脚本不作为题图下载。填空和简答的已填答案、隐藏表单、参考解析不进入题目文字。

整份图片按出现顺序去重，文件名带批次及 `001/002/...` 编号，对应本次文字导出的图片顺序。系统相册的默认展示顺序可能不同，发送时可按文件编号核对。单图失败不会中断其他图片，页面给出成功数量和失败图片编号；按题重试即可。

Android 10 及以上保存应用创建的图片无需整库相册权限。Android 8/9 只在用户点击保存时请求写入权限。支持常见 PNG、JPEG、GIF、WebP，也支持题目中的相同格式 base64 图片；GIF 保留原始内容。无法识别的来源、SVG等当前不支持格式或非图片响应会明确提示。

## 参考与实现

本轮对 `D:/study/xxt` 的相关项目交叉检索。可用题目结构来自 Helper 的 `.questionLi/.mark_name/.answerBg/.num_option/.answer_p` 与 Doraemon 的 Jsoup 解析；官方逆向 Java 的作业列表提供 `dotaskurl`，因此沿已有作业 URL 读取，不猜测或重建任务 ID/签名。

PassChaoxing 的 Python 字节码列出作业详情请求，但没有题目响应模型或样例，本功能没有把它当成已经核验的题目 API。其他本地签到、泄露查询等项目未找到可用的作业题目解析器。参考项目的自动作答、提交及外部图床流程没有接入。

读取模块固定当前账号会话，沿页面提供的地址读取；白名单主机之间的正常页面跳转逐次校验。已交作业可经过预览、报告、完整题目多层导航，支持页面中的字面量、隐藏输入绑定和固定字符串拼接，不执行 JavaScript。服务器提示无权限时明确报错，不显示为零道题。

未进入过的作业若只提供“开始答题”，页面先说明进入可能创建答题记录，必须点击「进入这份作业并读取题目」才继续。进入只获取页面，不填写、保存或提交答案。若出现官方认证要求，按提示完成后重试。

解析只收集题干和选项子树，保留段落、表格、上下标、常见 MathML 和 TeX 文本；共同题干保留在子题中。相册保存独立于解析，并对真实图片格式、大小、权限、取消和账户切换做检查。每批最多300张、每张最多12MiB；超过限制明确报错，不静默截断。

## 验证范围

v1.5.0 的初始参考项目没有真实作业页面样例。本次在用户授权的手机上采集真实返回页，修复手机 `.singleQuesId/.qtContent/.qtDetail` 与作答页 `.workWrap` 结构，补入脱敏后的合成回归。真机使用原生按钮核对剪贴板全文；保存题图后通过 MediaStore 逐张重新解码，并等待页面完整销毁。具体课程、数量、失败经过和最终通过结果见下方真机记录。

若页面未识别题目或报告缺失，应核对该页面的实际结构；界面不会把整个网页导航冒充题目内容，也不会将未识别项目悄悄标成全部成功。

本次真机结果见 [作业真机测试记录](device-homework-validation-2026-11-26.md)。v1.5.0 的初始合成测试记录保留在 [历史记录](validation-1.5.0.md)。
